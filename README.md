## 📲 Installer Mama sur Android

1. **Téléchargez** [Mama](https://github.com/karozadev/mama-releases/releases/latest/download/mama.apk) directement sur votre téléphone : le fichier `mama.apk` se télécharge sans autre étape.
2. **Ouvrez** le fichier téléchargé.
3. Si Android le demande, **autorisez l'installation** depuis votre navigateur ou votre gestionnaire de fichiers (« Installer des applications inconnues »). Cette autorisation n'est demandée qu'une fois.
4. Touchez **Installer**, puis **Ouvrir**.

> **Pourquoi pas le Play Store ?** Mama est distribuée directement ici pour le moment. L'application est signée : Android refusera d'installer une version qui n'a pas été signée par la même clé.

### Configuration requise

- Android 6.0 ou plus récent
- Une connexion internet (l'application vous prévient quand elle est coupée et se reconnecte toute seule)

## 🔄 Mises à jour

Vous n'avez rien à faire : **l'application cherche les nouvelles versions toute seule** au lancement.

Quand une version plus récente existe, Mama affiche *« Mama X.Y.Z est disponible »* avec la liste des nouveautés. Touchez **Mettre à jour** : elle télécharge la mise à jour, puis Android vous propose de l'installer. Vos données et votre compte sont conservés.

Vous pouvez aussi la chercher vous-même : **Profil → Rechercher une mise à jour**.

## 🔐 Vérifier le fichier

Chaque version est publiée avec un fichier `.sha256` (sur la [page de la version](https://github.com/karozadev/mama-releases/releases/latest)). Pour vérifier que votre téléchargement est intact, comparez l'empreinte :

```bash
sha256sum mama.apk
```

et comparez le résultat avec le contenu du fichier `mama-X.Y.Z.apk.sha256`.

Les APK sont signés avec la clé de release de Mama. Empreinte SHA-256 du certificat :

```
ac3a23f74de403ef24cefc832362af84fb7bbb4f214ff943fe8bf29508b2f2dc
```

Pour la lire vous-même : `apksigner verify --print-certs mama-X.Y.Z.apk`
